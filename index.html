El proyecto

¿Qué es?

Es una máquina que funciona con cartas de póker con tecnología RFID. El sistema mezcla el mazo de forma mecánica, lee la identidad de cada carta a través de sensores RFID y las reparte automáticamente a cada jugador, eliminando el mezclado manual y asegurando un reparto preciso y parejo.

01 · MEZCLAR

Un mecanismo mecánico agita y mezcla el mazo completo antes de cada mano.

02 · LEER

Cada carta lleva un tag RFID que el lector identifica al pasar por el sistema.

03 · REPARTIR

La máquina distribuye las cartas identificadas a cada jugador en orden.

Objetivos

Qué buscamos lograr

Automatizar el mezclado y reparto de cartas de póker mediante identificación RFID, reduciendo el error humano y el tiempo muerto entre manos.

01
AUTOMATIZAR

Eliminar el mezclado y reparto manual de cartas en la mesa.

02
IDENTIFICAR

Reconocer cada carta en tiempo real mediante lectores RFID.

03
REPARTIR PAREJO

Distribuir las cartas de forma equitativa entre todos los jugadores.

04
REDUCIR ERRORES

Minimizar errores humanos durante el mezclado y el reparto.
